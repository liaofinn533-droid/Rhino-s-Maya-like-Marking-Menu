# Rhino 标记菜单 v7.2（两级 · 圆形标签环 · 支持按住 Ctrl 模式）

仿 Maya 标记菜单，参考 RS2 的文字菜单交互。**两级选择，逻辑清晰**：

1. **第一级**：中心一圈"工具集"（如：曲线、圆、矩形、实体工具、变动…）。**点一下（或按住拖上去）选中一个工具集。**
2. **第二级**：选中的工具集**变成新的圆心**，它的具体工具绕成一个**圆形标签环**（一圈整齐排列），再点某个工具执行。

命令以**文字小方框 + 中心连线**呈现。二级不再是"扇形展开"的杂乱结构，而是独立成环、一眼看清。

## 文件说明（分包结构）

- `marking_menu.py` —— 主程序（运行核心；Rhino 别名/快捷键都指向它）
- `config.json` —— 配置：工具集 / 工具 / 命令 / 颜色 / 提示，改完立即生效（与主程序同目录）
- `README.md` —— 本说明（安装 / 使用 / 配置）
- `阶段总结.md` —— 项目阶段总结（当前迭代进度 v7.2）
- `preview/` —— 界面效果预览（`preview.png`、`menu_preview_v7.html`）
- `backup/` —— 旧版本备份（v2/v3 脚本、v6 配置）
- `tiles/` —— 参考素材（Rhino 默认工具面板截图切片）

## 一、安装（一次性，约 2 分钟）

1. 打开 Rhino 8。
2. 菜单 **工具 → 选项**（或命令行输入 `Options`）。
3. 左侧找到 **别名（Aliases）**。
4. 点"新建"，**别名**填 `MM`，**内容**填：

   ```
   _-RunPythonScript "F:\cod\Rhino-s-Maya-like-Marking-Menu\marking_menu.py"
   ```

   （路径里的引号要保留；如果以后移动了文件夹，只需改这里面的路径。）

5. 确定保存。

### 可选：用键盘快捷键呼出（按住 Ctrl 使用）

1. 菜单 **工具 → 选项 → 键盘（Keyboard）** → **新建**。
2. 按下你要用的组合键，例如 `Ctrl+Alt+M`（M = Marking Menu）。
3. 在**指令巨集**里粘贴这一行（和别名 MM 内容一样）：

   ```
   _-RunPythonScript "F:\cod\Rhino-s-Maya-like-Marking-Menu\marking_menu.py"
   ```

4. 确定保存。

设置后，**按住 `Ctrl+Alt+M`**：菜单出现在鼠标位置，**一直按着 Ctrl** 就能用（悬停选中、松手执行），松开后自动提交/关闭——像 Maya 标记菜单一样的手感。
如果只是按一下（不按住），菜单会立刻取消，属正常。

## 二、使用（两种方式）

### 方式 A：按住 Ctrl 使用（推荐，最快）

1. **按住** `Ctrl+Alt+M`（或你设的组合键）→ 菜单出现在鼠标位置。
2. **不要松开 Ctrl**，直接移动鼠标：
   - 移向某个工具集 → 它自动变成圆心，工具环展开（不用点）。
   - 移向环上的某个工具 → 工具高亮。
3. **松开 Ctrl**：
   - 停在高亮工具上 → 执行该工具。
   - 停在工具集方框上（没选具体工具）→ 执行该工具集的**默认工具**（= 第一个工具）。
   - 停在空白处 → 取消（菜单关闭，不执行任何命令）。
4. 想换工具集：移回中心原点，或直接移到其它变暗的工具集上。
5. `ESC` 随时关闭。

### 方式 B：普通点击使用（`_MM` 别名，不按 Ctrl）



1. 命令行输入 `_MM`（或 `MM`）→ 菜单出现在鼠标位置：中心一圈**工具集**。
2. **第一步——选工具集**：点一下某个工具集（或按住向它拖过去再松手），它就变成新的圆心。
3. **第二步——选工具**：它的工具绕成**一圈圆环**，点某个工具执行。
   - 选中后，**其它工具集自动变暗到约 10%**，只保留选中项高亮，画面干净、不会误点。
   - 也可以一步到位：按住从中心向工具集拖，圆环出现后**继续拖到某个工具上松手**，直接执行。
4. **切换/取消选择**：
   - 想换一个工具集：直接点背景里那个**变暗的工具集**，就切换过去（不用先退回）。
   - 点空白处或点中心的工具集方框 → 返回第一级重新选。
5. **取消/关闭**：快速点一级的空白处（没点到工具集）→ 取消；按 `ESC` 或点击菜单外 → 关闭。
6. 悬停在工具上会高亮并显示命令提示。

## 三、改配置（改完重新呼出即生效，无需重启 Rhino）

`config.json` 结构：**groups = 工具集列表**，每组下有 **tools = 工具列表**。

```json
{
  "menu_size": 460,
  "min_drag": 20,
  "groups": [
    {
      "name": "布尔",
      "color": "#E86496FA",
      "tooltip": "布尔运算",
      "tools": [
        { "name": "差集", "command": "BooleanDifference", "tooltip": "布尔差集 BooleanDifference" },
        { "name": "并集", "command": "BooleanUnion", "tooltip": "布尔并集 BooleanUnion" }
      ]
    }
  ]
}
```

字段说明：

| 字段 | 说明 | 示例 |
|---|---|---|
| `menu_size` | 菜单窗口尺寸（默认 460，过大时自动适配屏幕） | `460` |
| `min_drag` | 最小拖拽距离（像素） | `20` |
| `groups` | 工具集列表，每项一个工具集 | 见下 |
| `groups[].name` | 工具集显示的文字（建议 2-3 字） | `"布尔"` |
| `groups[].color` | 该工具集的高亮颜色，`#AARRGGBB` | `"#E86496FA"` |
| `groups[].tooltip` | 悬停提示 | `"布尔运算"` |
| `groups[].tools` | 该工具集下的工具列表 | 见下 |
| `tools[].name` | 工具显示文字（建议 2-3 字） | `"差集"` |
| `tools[].command` | 要执行的 Rhino 命令（英文名） | `"BooleanDifference"` |
| `tools[].tooltip` | 悬停提示（建议写英文命令名） | `"布尔差集 BooleanDifference"` |

**关于带选项的命令**：Rhino 里有些"命令"其实是某个命令的选项（如圆角矩形、三点矩形、中心矩形、直径画圆），直接写单独的名字会无效。正确写法是在命令后加选项，例如：

```json
{ "name": "圆角矩形", "command": "Rectangle _Rounded", "tooltip": "圆角矩形 Rectangle _Rounded" },
{ "name": "三点矩形", "command": "Rectangle _3Point", "tooltip": "三点矩形 Rectangle _3Point" },
{ "name": "中心矩形", "command": "Rectangle _Center", "tooltip": "中心矩形 Rectangle _Center" },
{ "name": "直径圆",   "command": "Circle _Diameter",   "tooltip": "直径画圆 Circle _Diameter" }
```

当前 `config.json` 里已经按这个规则写好。

- **加工具集**：在 `groups` 里加一项即可（4/6/8 个都行，方框自动均布）。
- **每组工具数**：圆形标签环对数量不敏感，2-8 个都整齐；太多可拆成两个工具集。
- **位置怎么排（不用填坐标，顺序即位置）**：
  - 第一级（工具集）在环上的位置 = `groups` 列表里的**先后顺序**：第 1 个从**右上方**开始，后面的沿**逆时针**排一圈（4/6/8/9 个都会自动均分角度）。
  - 第二级（工具）在环上的位置 = 每个 `tools` 列表里的**先后顺序**：第 1 个在**正上方**，后面的沿**顺时针**排一圈。
  - 想换位置 = 把列表项整段剪切粘贴到新位置即可。
- 旧版 `sectors` 配置仍可读取（会自动转成"单工具"的工具集），但建议直接用新的 `groups`。

当前默认 9 个工具集（对应你截图里的浮动面板）：**曲线、圆、曲线工具、矩形、建立曲面、曲面工具、从物件建、实体工具、变动**。
每个工具集里放的是常用的 Rhino 命令；图标型面板里的具体命令是识图辨认 + Rhino 标准对照的"最佳猜测"，建议在 Rhino 里悬停图标核对后，直接改 `config.json` 里的 `tools[].command` 即可。

## 四、界面风格

- **透明 + 白色柔光**背景：不压暗模型画面，菜单像浮在模型上的光晕。
- 两级结构：一级是中心一圈工具集；选中后以它为圆心生成**圆形工具标签环**（第二级独立成环，不再扇形展开）；未选中的其它工具集**自动变暗到约 10%**，只保留空间感。
- 圆角方框 + 玻璃高光 + 渐变中心圆点 + 拖拽进度环，蓝灰冷色调。
- 配色原则：中性深灰只做"底"，彩色只出现在高亮状态。

## 五、常见问题

- **点了工具集没反应**：确认是"点工具集"而不是"点空白"；点空白是取消/返回。
- **拖拽/点击后没执行**：检查 `config.json` 里 `command` 拼写；命令行会提示"命令不存在，已取消"。带选项的命令要写 `命令 _选项`（见上）。
- **想换工具顺序**：直接调整 `groups[].tools` 里的先后顺序即可（环上按顺序顺时针排列）。
- **屏幕边缘显示不全**：已自动限制在鼠标所在屏幕内；如果高分屏缩放异常，把 `menu_size` 调小。
